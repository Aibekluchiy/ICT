02 / DATA FLOW

From storage to execution.

When you launch a program, data travels through several parts of the computer before you see the result.

01

SSD

The program is stored as data on persistent storage.

02

RAM

Required instructions and data are copied into fast working memory.

03

CPU

The processor fetches instructions, decodes them and performs the required operations.

04

GPU

Graphics workloads are processed and converted into visual output.

03 / PROCESSOR

One instruction at a time.

At the heart of program execution is the CPU instruction cycle: fetch, decode, execute and write back.

01

FETCH

The CPU retrieves the next instruction from memory.

02

DECODE

The instruction is interpreted so the processor knows what operation is required.

03

EXECUTE

CPU execution units perform the requested operation.

04

WRITE BACK

The resulting value is written to the appropriate register or memory location.

05 / WHAT IF?

What happens when hardware changes?

Small changes in one component can affect the entire system.

Not enough RAM?

Click to see what happens.
The operating system may need to rely more heavily on slower storage for memory management, which can make multitasking feel less responsive.

Weak GPU?

Click to see what happens.
Graphics workloads can become the limiting factor, especially in applications that rely heavily on GPU processing.

Slow storage?

Click to see what happens.
Reading large files and launching applications can take longer because the system must wait for data from storage.

Slow CPU?

Click to see what happens.
Tasks that depend strongly on CPU computation may take longer to complete.

No power?

Click to see what happens.
The components cannot operate without the electrical power supplied by the power system.

Motherboard failure?

Click to see what happens.
Because the motherboard connects many of the major components, a failure can prevent communication between them.
